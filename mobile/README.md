# Office Werkstatt for Android

The Android app is a [Capacitor 8](https://capacitorjs.com) shell around the same web app (`../public`).
`public/js/mobile.js` switches on inside the app (and the phone layout in `public/css/editors.css` on every small screen):

| | |
|---|---|
| **AI on the phone** | [llama.cpp](https://github.com/ggml-org/llama.cpp) through [`@cantoo/capacitor-llama`](https://github.com/cantoo-scribe/capacitor-llama) (MIT, prebuilt arm64-v8a / x86_64 libraries). GGUF models are downloaded once from Hugging Face into the app's data folder (Settings › AI › Built-in). Tool calls are emulated in the prompt (`<tool_call>{"name", "arguments"}</tool_call>`, the Qwen/Hermes format), so the agent works as on the desktop. |
| **Ollama / API** | `CapacitorHttp` sends requests natively – no CORS; cleartext HTTP is allowed for Ollama in the home network. |
| **Web research** | `web_search` / `fetch_page` run in the app (SearXNG, Bing RSS, DuckDuckGo lite, Wikipedia); local network addresses are refused. |
| **Files** | Downloads (blob links, also from the engine frames) are written to *Documents/Office Werkstatt* and offered in the share sheet. *Open with* (VIEW intents) imports documents into the library. |
| **Phone UI** | ≤ 640 px: the commands sit at the bottom – tab picker, one scrolling row, a sheet with all commands; menus and dialogs are bottom sheets; `⋯` holds search, share, comments, language, theme. |

## Build

Needs Node 20+, JDK 21 and the Android SDK (`ANDROID_HOME`).

```bash
cd mobile
npm install                      # also downloads the llama.cpp libraries of the plugin
npm run android:prepare          # www/ from ../public, `cap add android`, manifest, icons, signing, `cap sync`
cd android && ./gradlew assembleRelease
```

`android/` is generated by `scripts/prepare-android.mjs` and not kept in git. The version comes from the root `package.json`.

**Signing:** without environment variables the APK is signed with the project's public development key
(`ow-dev.keystore.b64`), so every build installs over the previous one. For your own key set `OW_KEYSTORE`,
`OW_KEYSTORE_PASSWORD`, `OW_KEY_ALIAS`, `OW_KEY_PASSWORD` – in GitHub Actions the secrets
`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
(An APK signed with another key cannot update one signed with the development key – uninstall first.)

The GitHub workflow *Android APK* (`.github/workflows/android.yml`) builds the APK for every published release and attaches
`Office-Werkstatt-<version>.apk`; *Run workflow* builds one by hand.
